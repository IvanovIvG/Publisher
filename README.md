1) В корне проекта создаем файл файл database_properties.env, копируем туда содержимое database_properties_origin.env
2) Записываем туда username и password базы данных. Тот который мы хотим чтобы там был.
3) Запускаем через docker-compose

Приложение работает на порту 8080
Swagger документация доступна по http://localhost:8080/swagger-ui/index.html
